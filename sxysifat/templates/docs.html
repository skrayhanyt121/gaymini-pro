POST /api/gemini All-in-One

One endpoint for everything. Auto-detects mode from your input — send text for chat, mention image keywords for generation, upload an image for vision or editing.

Modes: auto chat image music video vision edit generate explain debug convert review optimize test document complete ask
Extra fields: language target_language context chat_id

{
  "message": "Explain quantum computing",
  "mode": "auto"
}
{
  "text": "...",
  "images": [{ "url": "...", "data_url": "data:image/..." }],
  "chat_id": "c_abc123...",
  "mode": "chat"
}
# Chat
curl -X POST BASE_URL/api/gemini \
  -H "Content-Type: application/json" \
  -d '{"message": "Tell me a joke"}'

# Vision (upload image)
curl -X POST BASE_URL/api/gemini \
  -F "image=@photo.jpg" \
  -F "message=What is in this image?"
import requests
r = requests.post("BASE_URL/api/gemini", json={
    "message": "Hello!"
})
print(r.json()["text"], r.json()["mode"])

GET /api/chat/stream SSE Streaming

Real-time streaming via Server-Sent Events. Response arrives token-by-token.
Query params: message model chat_id

// Keep-alive
data: {"type": "ping"}
// Text chunk
data: {"type": "chunk", "text": "Hello"}
// Done
data: {"type": "done", "chat_id": "c_abc123..."}
const es = new EventSource(
  `BASE_URL/api/chat/stream?message=Hello`
);
es.onmessage = e => {
  const d = JSON.parse(e.data);
  if (d.type === "chunk") process.stdout.write(d.text);
  if (d.type === "done") es.close();
};

POST /api/video Generate video

Generate a video from a text prompt, or animate an uploaded image according to a prompt, using the bundled Gemini client. Gemini must return a generated video for the current account and model. The response contains a Gemini-hosted video URL and thumbnail. Generation may take several minutes; allow up to 8 minutes for the request.

# Prompt only
curl -X POST BASE_URL/api/video \
  -H "Content-Type: application/json" \
  -d '{"prompt":"A cinematic aerial shot over a misty mountain lake at sunrise"}'

# Image + prompt (image-to-video)
curl -X POST BASE_URL/api/video \
  -F "image=@photo.jpg" \
  -F "prompt=Make the person wave and slowly zoom in"
{
  "prompt": "A cinematic aerial shot over a misty mountain lake at sunrise",
  "model": "unspecified"
}
{
  "videos": [{ "url": "...", "thumbnail": "...", "type": "GeneratedVideo" }],
  "text": "...",
  "chat_id": "...",
  "mode": "video"
}

Alias: POST /api/video/generate. The all-in-one endpoint also accepts "mode": "video". Upload an image with the image field to animate that image according to the prompt.

POST /api/deep-research Full research report

Gemini Deep Research. Multi-step research cycle — generates a plan, executes it, returns a full structured report. Takes 1–5 minutes.
topic: required. max_polls: default 20. poll_interval: seconds (default 15).

{
  "topic": "Impact of AI on healthcare in 2025",
  "max_polls": 20,
  "poll_interval": 15
}
{
  "topic": "...",
  "report": "## Report\n\n...",
  "plan": "...",
  "polls": 8
}
curl -X POST BASE_URL/api/deep-research \
  -H "Content-Type: application/json" \
  -d '{"topic": "Future of renewable energy"}' \
  --max-time 300
